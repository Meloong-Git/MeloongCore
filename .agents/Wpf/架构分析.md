# Wpf 入口与构建

[代码约定](../仓库指示.md) · [Shared](../Shared/架构分析.md)

构建 WPF 工程使用 Visual Studio 2022 的 `MSBuild.exe`。本项目为通用 Windows/WPF 适配层，依赖 Shared；纯 .NET 逻辑留在 Shared，应用专用外观和页面逻辑留在引用方。

路径相对于 `Wpf/`：

| 场景 | 入口 |
| --- | --- |
| WPF 初始化 | `Main.cs` |
| ToolTip 附加行为 | `Controls/ModernTooltipService.cs` |
| 控件与对象扩展 | `Extensions/WpfExtensions.cs` |
| 文件、文件夹与消息对话框 | `General/Dialogs.cs` |
| Binding 转换器 | `General/ValueConverters.cs` |
| Windows 权限、窗口与系统操作 | `Utils/WindowsUtils.cs` |

System.Windows.Forms 与 WPF 互操作涉及 DPI、窗口句柄和线程模型；调整相关行为时检查调用线程与窗口归属。
