# MeloongCore 代码约定

## 风格与复用

- 使用 C# 13、Nullable、Implicit Usings 和 PolySharp；保持目标框架兼容。
- 保持改动精简、结构紧凑并保留必要注释；避免无实际收益的抽象、优化和防御性检查。
- 不为一两行逻辑添加辅助方法；仅有一个引用的方法或变量优先考虑内联。
- 新增工具前检查现有 Extensions、General 和 Utils，避免重复实现。

## C# 风格

- 大括号不换行；变量名小驼峰，类型、属性和方法名大驼峰。
- 无 `else`、简短且仅一条语句的 `if` 写成 `if (flag) break;`；换行则加大括号。单行大括号内部不留首尾空格，如 `{element}`。
- 行尾注释格式为 `break; // 注释`；XML 文档参数引用用 `<paramref name="..."/>`。
- 使用 `""` 表示空字符串；优先采用 C# 13 下简洁清晰的写法。

## 公共 API 与平台边界

- Shared 承载跨产品通用能力；Windows/WPF 特有功能优先放入 Wpf，已有平台专属入口需保持明确的调用边界。
- 上层应用的业务、页面和全局状态留在引用方；Tests 只保护本库公共行为，不反向依赖应用项目。
- 修改公共 API 签名或语义时检查已有引用方的兼容性。
