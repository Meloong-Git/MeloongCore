# MeloongCore.Tests 项目架构

[返回 MeloongCore 仓库指示](../仓库指示.md)

## 1. 项目定位

`MeloongCore/Tests/MeloongCore.Tests.csproj` 是基于 TUnit 的 .NET Framework 4.8 测试程序，同时引用 `MeloongCore` 与 `MeloongCore.Wpf`。

它主要保护通用基础库，不覆盖引用本库的上层应用业务。

## 2. 测试范围

| 测试文件 | 覆盖能力 |
| --- | --- |
| `General/ConfigTest.cs` | JSON 配置读写、默认值与缓存 |
| `General/ProgressTest.cs` | 进度切分与聚合 |
| `General/WorkerTest.cs` | Worker 调度、限流或重做语义 |
| `Utils/CryptographyUtilsTest.cs` | 加密工具 |
| `Utils/DirectoryUtilsTest.cs` | 目录操作 |
| `Utils/FileUtilsTest.cs` | 文件与压缩包处理 |
| `Utils/PathUtilsTest.cs` | 路径规范化和关系判断 |
| `Utils/TaskUtilsTest.cs` | 异步任务与进程能力 |
| `TestUtils.cs` | 测试公共支持 |

`TestFiles/FileUtils` 中包含正常、损坏、不同编码和恶意路径的压缩包样本，用于验证 Zip Slip 等边界。

## 3. 项目特点

- 输出类型为 `Exe`，由 TUnit 测试运行机制执行；
- 测试资源复制到输出目录；
- 同时引用 WPF 层，因此可以覆盖少量 WPF 相关基础能力。

## 4. 测试缺口

当前测试主要集中于 Shared 的通用工具、配置、进度与 Worker，Wpf 层的平台行为覆盖仍较少。

## 5. 建议

测试范围应保持在 MeloongCore 的公共行为内：

1. 保持本项目只测试 MeloongCore 与 WPF 适配层；
2. 上层应用的业务测试由对应应用仓库维护；
3. 新增公共能力时，优先补充与其行为和平台边界相对应的测试。
