# Tests 定位与环境

[代码约定](../仓库指示.md) · [WPF 构建要求](../Wpf/架构分析.md)

Tests 是 TUnit 可执行测试项目，引用 Shared 与 Wpf，运行目标为 .NET Framework 4.8；其运行结果不能证明 macOS 兼容性。运行机制和资源复制配置见 [项目文件](../../Tests/MeloongCore.Tests.csproj)。

| 修改能力 | 对应测试目录或文件（相对于 Tests/） |
| --- | --- |
| 配置、进度、Worker | `General/` |
| 加密、目录、文件、路径、任务和进程 | `Utils/` |
| 初始化、日志接入、临时目录 | `TestUtils.cs` |
| 压缩格式、编码、损坏文件与 Zip Slip | `TestFiles/FileUtils/` |

[TestUtils.cs](../../Tests/TestUtils.cs) 中 TestBase 初始化 MeloongCore 并接入测试日志；TestWithFolder 在系统临时目录下创建含 GUID、特殊字符和长路径的测试目录，样本从输出目录复制。

测试目前主要覆盖 Shared，引用 Wpf 不意味着已覆盖其平台行为。按本次修改选择相关行为验证，上层应用业务测试留在引用方仓库。
